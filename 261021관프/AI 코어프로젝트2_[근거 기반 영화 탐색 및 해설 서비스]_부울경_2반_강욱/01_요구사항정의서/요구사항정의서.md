# 요구사항 정의서

## 1. 선택 도메인과 조건 충족 근거

주제는 **근거 기반 영화 탐색 및 해설 서비스(Movie Lab)**다. 영화 정보와 작품 속 과학·역사 배경을 문서에 근거해 설명하고, 조건에 맞는 영화를 탐색한다.

| 조건 | 충족 근거 |
|---|---|
| 항목 수 | 제공 movies.json의 영화 964편, 이 중 한국어 영화 168편으로 100건 이상 조건 충족 |
| 항목별 정보 | 제목·원제·개봉연도·장르·감독·출연·상영시간·언어·제작국가·평점·줄거리 |
| 외부 문서 | 제공 한국어 위키백과 묶음 3,725파일, 연결 영화의 NASA PDF 2~4쪽 |
| 근거의 필요성 | 작품 메타데이터와 과학·역사적 사실을 구분하고 확인할 수 없는 정보를 추측하지 않기 위해 원문 근거 사용 |

### 문서 출처와 이용 조건

- 영화 메타데이터: 교육용 TMDB 기반 배포 JSON과 각 항목의 tmdb_url. 제공처 안내 및 [TMDB 이용 조건](https://www.themoviedb.org/terms-of-use)을 따른다.
- 위키백과: 한국어 위키백과 및 제공 묶음의 원문 URL. 제공 안내의 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)에 따라 출처와 이용 조건을 보존한다.
- PDF: NASA Goddard의 [A Field Guide to Black Holes](https://science.nasa.gov/resource/a-field-guide-to-black-holes-booklet/). [NASA 이용 지침](https://www.nasa.gov/nasa-brand-center/images-and-media/)과 원문 제3자 크레딧을 보존하며 텍스트 검색에 사용한다.

### 근거가 필요한 질문 예시

1. 제공 영화 데이터에서 인터스텔라의 상영 시간과 감독은 무엇인가?
2. 블랙홀의 사건의 지평선은 무엇이며 빛이 빠져나올 수 있는가?
3. 블랙홀의 주요 질량 범주와 대략적인 범위는 무엇인가?
4. 명량이 다루는 역사적 전투의 배경은 무엇인가?
5. 쿠퍼의 우주복 소품 제조 일련번호가 자료에 있는가? 없으면 확인 불가로 안내해야 한다.

## 2. 필수 기능 요구사항 (F2001~F2012)

| ID | 요구사항 | 요구 내용 |
|---|---|---|
| F2001 | 영화 데이터 로드와 항목별 텍스트 | 964편(한국어 168편), 제목·원제·연도·장르·감독·출연·줄거리 등 결합 |
| F2002 | 메타데이터 임베딩 및 별도 컬렉션 | 고정 movie_id, content_hash, 변경분 upsert |
| F2003 | 전문가 역할 검색어 추출 | 영화 큐레이터 프롬프트, JSON 배열 최대 3개 + 작품 자체 검색어 |
| F2004 | 외부 문서 후보 선별·수집 | 제목·요약 후보→LLM page_id 선별→본문·URL 저장, 자체 문서 필수, 검색어 캐시 |
| F2005 | 외부 문서 청킹·임베딩 | 위키/PDF 외부 컬렉션, 기본 1000/200, 영화ID:문서ID:청크번호 |
| F2006 | 선택 영화 범위 검색·병합 | 영화 메타 1개 고정 + 외부 의미 검색, 중복 제거, Top-k 상한 |
| F2007 | LangGraph 답변 생성 | retrieve/generate 2노드, 원문만 사용, 없으면 확인 불가 |
| F2008 | 인용 번호와 원문 근거 | 실제로 인용한 번호만 제목·URL·종류와 함께 표시 |
| F2009 | 영화별 대화 관리 | 영화 ID별 이력, 웹 세션 분리 |
| F2010 | 영화 관람 가이드 | 작품 소개·배경·확인 불가 사항, 동일 RAG 근거 정책 |
| F2011 | 자연어 조건 탐색 | 명시 조건 필터→의미 검색→후보 LLM 검증→영화 카드 |
| F2012 | 진행·오류·부족 상태 안내 | 진행, 키 없음, 색인 없음, 확인 불가, 안전한 오류 |
