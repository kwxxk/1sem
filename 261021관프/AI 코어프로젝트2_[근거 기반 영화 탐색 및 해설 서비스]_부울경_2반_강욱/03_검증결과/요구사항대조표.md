# 요구사항 정의서

주제: 근거 기반 영화 탐색 및 해설 서비스 (Movie Lab)

기준: 제공 명세서의 필수 F2001~F2012, 선택 심화 F2013~F2016, 비기능 NF2001~NF2007. 2026-10-21 최종 코드 및 실제 검증 기록 기준.

## 기능별 요구사항 및 대조표

| ID | 요구사항 | 구현 내용 | 확인 상태 |
|---|---|---|---|

| F2002 | 메타데이터 임베딩 및 별도 컬렉션 | 고정 movie_id, content_hash, 변경분 upsert | 실제 964건 / 재색인 변경 0건 |
| F2003 | 전문가 역할 검색어 추출 | 영화 큐레이터 프롬프트, JSON 배열 최대 3개 + 작품 자체 검색어 | 실제 대표 질문 및 수집 로그 확인 |
| F2004 | 외부 문서 후보 선별·수집 | 제목·요약 후보→LLM page_id 선별→본문·URL 저장, 자체 문서 필수, 검색어 캐시 | 대표 영화 확인 / 묶음 13편의 자체 문서 식별 제약 |
| F2005 | 외부 문서 청킹·임베딩 | 위키/PDF 외부 컬렉션, 기본 1000/200, 영화ID:문서ID:청크번호 | 실제 외부 청크 89개(검증 시점), 재청킹 자동 검사 |
| F2006 | 선택 영화 범위 검색·병합 | 영화 메타 1개 고정 + 외부 의미 검색, 중복 제거, Top-k 상한 | 실제 검색 및 범위·상한 자동 검사 |

| F2008 | 인용 번호와 원문 근거 | 실제로 인용한 번호만 제목·URL·종류와 함께 표시 | 실제 웹 캡처와 원문 대조 |
| F2009 | 영화별 대화 관리 | 영화 ID별 이력, 웹 세션 분리 | 실제 웹 영화 전환·복원 확인 |

| F2012 | 진행·오류·부족 상태 안내 | 진행, 키 없음, 색인 없음, 확인 불가, 안전한 오류 | 실제 진행 및 모의 오류/누락 상태 검사 |

| F2016 | 여러 외부 출처 결합 (선택) | 위키와 NASA PDF, PDF 페이지·이용 조건·유형 보존 | 실제 PDF 인용 확인 |

## 비기능 요구사항

| ID | 요구사항 | 구현 및 확인 |
|---|---|---|
| NF2001 | 응답 시간 | 최초 질문별 3.064~7.443초, 최종 반복 0.963~1.875초. 캐시 및 단일 환경 조건 별도 명시 |
| NF2002 | 중복 수집 방지 | 영화/검색어별 완료 캐시, 반복 질문에서 collection_cached=true |
| NF2003 | 키 관리 | 실행 환경 .env에만 키 저장. 제출 사본에서 .env·venv·.local을 제외 |
| NF2004 | 비밀·오류 비노출 | 공개 오류 치환, 키·전체 프롬프트 로그 방지, textContent/CSP, /.env 404 확인 |
| NF2005 | 모듈 분리 | preparation, store, retrieval/pipeline, service, webapi/web, Streamlit |
| NF2006 | 외부 호출 정책 | 간격·최대 재시도·Retry-After·User-Agent 연락처 구현. 실제 검증은 제공 묶음 사용, 위키 API 정책은 모의 검사 |
| NF2007 | 출처·이용 조건 | 원문 URL, 유형, 라이선스, PDF 쪽·체크섬 보존 |

## 알려진 제약

영화 964편 전체의 외부 문서/답변 품질을 검증한 것은 아니다. 배포 묶음의 13편은 자체 문서 식별이 제한된다. 실제 위키 API 연결과 사람의 셀프·상호 점검은 미완료다. 위험/미확인 항목은 통과로 표기하지 않았다.
