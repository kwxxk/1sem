# 필수 구현과 심화 적용 결과 비교

| 선택 기능 | 필수 구현 | 심화 적용 | 확인 결과와 증빙 |
|---|---|---|---|
| F2013 | Streamlit에서 질문·답변·근거 표시 | HTML/CSS/JS와 FastAPI로 화면/API 분리 | 동일 Service 사용. 기본 Streamlit은 자동 검사, 심화 웹은 실제 Edge 질문·가이드·대화 복원 확인. 실행화면/11_검색어_문서채택_제외.png |
| F2014 | 선택 영화 범위의 의미 유사도 검색 | 동일 질문·색인·Top-k에서 MMR과 근거 목록 비교 | 실제 근거 ID가 달라짐. 실행화면/20_동일질문_유사도_MMR.png 및 실행기록/live_verification.json. 차이 자체가 더 높은 정확성을 의미하지는 않음 |
| F2015 | 근거를 붙인 답변 제공 | 같은 모델·질문 5개에 문서 미사용/사용 답변 비교 | RAG_전후비교_실제결과.md와 GMS_실제검증결과.md. 기본 영화 정보와 확인 불가 응답은 미사용 답변도 적절했고, RAG 답변은 원문 대조가 가능함 |
| F2016 | 위키백과 기반 외부 근거 | 위키와 NASA PDF를 같은 외부 컬렉션에서 검색하고 유형·쪽 표시 | 블랙홀 질량 범주 답변에서 PDF 2쪽 인용 확인. 영어 PDF 검색 누락 보완 후 원문 범위 대조 |

실제 비교의 대표 영화는 인터스텔라다. 전 영화·전 질문의 품질 향상이나 설정별 정답률 향상을 증명한 것은 아니다. 사람의 비교 검토 완료 여부는 별도로 관리한다.


2026-10-23 동일 코드의 실제 웹에서 5쌍 답변을 다시 수집했고 25번 캡처를 추가했다. 청킹별 외부 청크는 195개/63개/기본 복원 89개, Top-k는 실제 2건/6건으로 확인했다.
