# RAG 전후 비교 — 실제 실행 대기

실제 GMS 키를 사용한 답변은 아직 없다. 이 문서는 비교 계획이며 결과 보고서가 아니다.
실행 도구와 자동 테스트는 준비되어 있다. 테스트 모델의 출력·측정치를 실제 모델 결과로 옮기지 않는다.

| 질문 | 검토할 근거 | 상태 |
|---|---|---|
| 제공 데이터에서 인터스텔라의 상영 시간과 감독은? | movies.json의 runtime·director | 실제 응답 대기 |
| 인터스텔라의 제작 국가와 개봉 연도는? | production_countries·year | 실제 응답 대기 |
| 사건의 지평선은 무엇이며 빛이 빠져나올 수 있는가? | NASA PDF 2쪽 및 위키 | 실제 응답 대기 |
| 관측된 블랙홀의 주요 두 질량 범주와 범위는? | NASA PDF 2쪽 | 실제 응답 대기 |
| 쿠퍼 우주복 소품의 제조 일련번호 전체는? | 색인에 없을 때 확인 불가로 처리하는지 | 실제 응답 대기 |

웹의 검색·답변 비교에서 실행한 뒤 RAG 미사용/사용 답변을 원문과 대조한다.
사실 정확성·근거 표시·확인 불가 처리를 비교하고 각 질문의 평가와 이유를 저장한다.
5개 질문 전부 검토한 뒤 보고서를 내려받아 제출물에 포함한다.
CLI: `python manage.py evaluate` → 출력된 UUID를 이용해
`python manage.py export-evaluation --id UUID --output docs/RAG_전후비교_실제결과.md`.
CLI 실행만으로 사람의 원문 대조 평가가 끝나는 것은 아니다.
