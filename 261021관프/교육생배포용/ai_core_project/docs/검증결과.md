# 검증 결과

검증일: 2026-10-21. 실제 GMS 키가 아직 없으므로 외부 모델 호출은 수행하지 않았다.
실제 서비스의 셀프·상호 점검 결과를 대신하는 문서가 아니다.

## 자동 테스트

명령: `.\.venv\Scripts\python.exe -m unittest discover -s tests -v`

| 테스트 | 확인 결과 |
|---|---|
| 항목 메타데이터 재색인 | 2회 실행해도 항목 수 유지, 변경 없는 항목 재임베딩 생략 |
| 공유 위키 문서 식별자 | 영화 ID별 청크가 각각 보존됨 |
| 청크 설정 변경 | 청크 수 변경, 기존 뒤쪽 청크 제거, 재실행 시 증가 없음 |
| 선택 영화의 근거 검색 | 메타데이터 필수 포함, 다른 영화 제외, Top-k 변경 반영 |
| 필수 문서와 수집 캐시 | 선별 결과가 비어도 영화 자체 문서 색인, 반복 질문 외부 검색 생략 |
| LangGraph | retrieve/generate 두 노드로 실행 |
| 인용 검사 | 없는 인용·범위 밖 인용 차단, 실제 번호만 표시 대상으로 추출 |
| 항목 문서 판별 | 개봉연도가 다른 작품·드라마 제외 |
| 조건 탐색 | 수치·언어·장르 조건 위반 항목 제외, 잘못된 조건 거부 |
| 키 없는 화면 | 안내 표시, 채팅 비활성화, 영화별 대화 보존 |
| 색인 없는 화면 | 색인 안내 및 채팅 비활성화 |
| UI 연결 | 테스트 모델로 질문·관람 가이드·조건 탐색이 실제 UI에서 동작 |
| 도메인 분리 | 별도 도서 어댑터로 공통 Store·LangGraph가 영화 필드 없이 동작 |
| 관람 가이드 분리 | 서비스가 도메인의 요청·생성 지침으로 같은 근거 파이프라인 실행 |

14개 자동 테스트 통과. Chroma/LangGraph/Streamlit은 실제 라이브러리이고,
벡터·LLM 출력만 테스트 전용으로 대체했다. 외부 호출은 하지 않는다.

## 실제 키 설정 후 확인할 항목 — 모두 미확인

- GMS 모델 및 임베딩 모델 접근 권한, 실제 메타데이터 964건 색인
- 동일 색인 명령 2회 실행 시 964건 유지 증빙
- 실제 질문의 검색어·채택/제외 문서·영화 자체 문서 확인
- 위키 API 검색·원문 수집·연락처·요청 제한·제공 문서 대체 흐름
- 같은 질문의 실제 수집 로그 및 첫 질문/반복 질문 시간 비교
- 청크 크기·중복 길이·Top-k 조정 후 실제 근거 목록 및 품질 비교
- 답변 주요 주장과 인용 내용의 의미상 일치 여부
- 근거 없는 질문의 추측 방지, 실제 관람 가이드 품질
- 실제 자연어 조건 5개 이상의 탐색 정확성
- 정상·오류 화면에서 비밀 정보가 보이지 않는지 확인
- 화면 캡처 첨부 및 제공 셀프·상호 체크리스트 작성
