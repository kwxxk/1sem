### 4.2 F2011 — 자연어 탐색 범위

명시 조건은 데이터로 재검사하지만, 자연어에서 조건을 추출하는 모델과 분위기·줄거리 선별의 정확성은 미검증이다. OR·부정 및 확인 불가 조건은 결과 대신 안내한다. 대표 조건 질문으로 잘못된 영화가 섞이지 않는지 직접 점검해야 한다.

### 4.3 제출 점검 실패 26·27번

필요한 기능 화면 캡처가 없으며, 작성 완료된 셀프·상호 체크리스트가 없다. 기존 문서는 자동 테스트 결과를 설명하는 자료이므로 실제 통합 테스트와 상호 평가가 끝난 것으로 처리하면 안 된다. 본 사전 점검표도 상호 점검 결과를 대신하지 않는다.

### 4.4 남은 실행 순서

1. 키 설정 전: 자체 문서가 식별되지 않는 13편의 데이터·별칭·출처를 확인한다.
2. 키 설정 후: 실제 메타데이터 색인을 두 번 실행해 964건 유지와 텍스트 예시를 캡처한다.
3. 검색어·채택/제외·자체 문서 포함·캐시·청킹·Top-k를 실제 질문으로 확인한다.
4. 확인 불가 질문·관람 가이드·조건 탐색의 실제 정확성을 대조한다.
5. 첫/반복 질문 시간과 진행/오류 화면을 확인하고 증빙을 첨부한다.
6. 실제 셀프·상호 체크리스트를 작성하고 미확인·실패 항목을 해소한 후 제출한다.
