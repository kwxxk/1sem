# Movie Lab 필수 요구사항

기준: 상위 폴더의 `AI코어프로젝트_2회차_요구사항정의서.pdf` 9~15쪽 및 제공 체크리스트.
문서 안의 제출·검증 지침은 요구사항으로 반영하며, 외부 업로드는 수행하지 않는다.

## 도메인

- 영화 964편, 한국어 영화 168편: 약 100건 이상 조건 충족.
- 메타데이터 출처: 배포된 TMDB 기반 JSON. 원문 링크 보존.
- 외부 문서: 한국어 위키백과 API / 호출 제한 시 제공 묶음 3,725개 문서 파일.
- 이용 조건: 위키 문서는 CC BY-SA 4.0, TMDB 데이터는 제공처 및 TMDB 이용 조건 확인.
- 위험 판단 도메인 여부: 해당 없음.
- 근거가 필요한 질문 예시:
  1. 인터스텔라에 나오는 웜홀과 블랙홀은 어떤 개념인가?
  2. 명량이 다루는 역사적 전투의 배경은 무엇인가?
  3. 기생충의 작품 정보와 감독의 이력에서 확인되는 사실은 무엇인가?

## 요구사항 대조표

| ID | 구현 | 검증 및 상태 |
|---|---|---|
| F2001 | preparation/movies.py, manage.py inspect | 배포 데이터 건수 확인, 색인 텍스트 구성 |
| F2002 | Store.index_items | 고정 ID upsert, 반복 색인 테스트. 실제 임베딩 미확인 |
| F2003 | Collector 검색어 프롬프트 | JSON 배열, 항목 자체 검색어 우선. 실제 LLM 출력 미확인 |
| F2004 | WikiAPI/Bundle + 선별 프롬프트 + 캐시 | 항목 문서 강제 포함·중복 수집 방지 자동 검증. API 미확인 |
| F2005 | Store.index_document | 별도 컬렉션, 설정 청킹, 충돌 방지 ID, 재청킹 자동 검증 |
| F2006 | Store.retrieve | 항목 메타 필수, 영화 범위 필터, 중복 제거, Top-k 자동 검증 |
| F2007 | pipeline.py | retrieve/generate 두 노드, 근거 제한 프롬프트, 실제 정확성 미확인 |
| F2008 | citations.cited_sources, app.render_sources | 인용 번호 검사, 실제 인용만 표시, 없는 경우 안내 |
| F2009 | movie_histories[movie_id] | 영화 전환 및 이전 대화 보존 자동 검증 |
| F2010 | 관람 가이드 버튼 | 동일 수집·검색·생성 파이프라인 사용. 실제 품질 미확인 |
| F2011 | explore.py + 카드 선택 | 구조화 필터·의미 검색·후보 검증. 실제 자연어 해석 품질 미확인 |
| F2012 | app.py | 키 없음·색인 없음 자동 검증, 진행 및 오류 안내 구현 |

심화 F2013~F2016: 모두 선택하여 코드 및 로컬 검증을 추가했다. 실제 GMS 비교·품질 검증은 대기 중이다. F2016은 메타데이터/위키 구분 자체가 아니라 위키와 PDF 등 **서로 다른 외부 출처** 결합이다.

NF2001: 실제 처리 시간 측정 대기 / NF2002: 검색어 캐시 / NF2003: .env 및 gitignore /
NF2004: UI 일반 오류 메시지 / NF2005: 모듈 분리·도메인 어댑터 주입 / NF2006: 간격·재시도·연락처 /
NF2007: README 출처·조건 기록.

## 심화·비기능 추가 구현

F2013: web/ + webapi/의 HTML/CSS/JS·API 분리.
F2014: 유사도/MMR 선택과 같은 질문의 근거 비교.
F2015: 대표 질문 5개, RAG 전후 응답·사람 평가·보고서 내보내기.
F2016: NASA PDF 페이지별 수집·위키와 같은 외부 컬렉션·출처 유형 표시.
NF2001~NF2007의 구현과 검증 한계는 심화_비기능_구현검증.md를 기준으로 확인한다.
