# 1.3 작업 순서와 현재 진행 상태

원본 PDF 6쪽의 1.3 항목을 기준으로 작성했다.
최초 구현에서는 기획·설계·코드를 일부 함께 작성했으므로 1~16번을 순차 완료했다고
볼 수 없다. 이 문서는 현재 산출물을 순서에 맞춰 점검하기 위한 대조표이며,
실제 수행 이력을 소급해 바꾸는 문서가 아니다.

GMS 키가 아직 없고 실제 외부 모델 호출은 수행하지 않았다.
테스트 전용 모델로 동작을 확인한 항목과 실제 서비스 검증을 구분한다.

| 순서 | PDF 작업 | 현재 상태·근거 | 남은 확인 |
|---|---|---|---|
| 1 | 필수·심화 요구사항 검토 | PDF와 체크리스트 검토, 필수 F2001~F2012 구현 범위 정의 | 실제 실행 대조 |
| 2 | 도메인 확정·조건 세 가지 확인 | 영화 기본 도메인, 964편·문서 출처·질문 예시 문서화 | 데이터 외부 재배포 허용 범위 확인 |
| 3 | 항목 1건 색인 텍스트 설계 | preparation/movies.py, 제목·원제·연도·장르·감독·출연·줄거리 등 | 실제 검색 품질 |
| 4 | 컬렉션·메타데이터 설계 | MovieDomain에 두 컬렉션·필드·식별자 정의 | 실제 GMS 임베딩 적재 |
| 5 | 세 프롬프트 역할·출력 형식 설계 | preparation/prompts.py | 실제 출력 형식·내용 |
| 6 | 메타데이터 임베딩·색인 | 코드 구현, 테스트 벡터로 중복 방지 검증 | 실제 964편 임베딩 대기 |
| 7 | 검색어 추출 프롬프트 작성 | JSON 배열, 영화 자체 검색어 추가 | 실제 질문의 검색어 검증 |
| 8 | 외부 검색·선별·본문·출처 수집 | 코드 구현, 제공 문서/캐시/필수 문서 테스트 | 실제 LLM 선별과 API 검증 |
| 9 | 외부 문서 별도 컬렉션 색인 | 청킹·임베딩 코드, 재청킹 테스트 | 실제 문서 색인 대기 |
| 10 | 두 컬렉션 검색·병합·중복 제거 | 필수 메타데이터+항목 필터+Top-k 테스트 | 실제 근거의 관련성 |
| 11 | 답변 프롬프트·LangGraph 구성 | retrieve/generate 구현·실행 테스트 | 실제 답변 정확성·확인 불가 응답 |
| 12 | 사용한 근거 제목·출처 표시 | 인용 번호 검사 및 UI 연결 테스트 | 주장과 문서 내용의 의미상 일치 |
| 13 | 선택·질문·조건 탐색·특화 기능 UI | 구현 및 테스트 모델로 UI 검증 | 실제 조건 해석·관람 가이드 품질 |
| 14 | 진행·비정상 상태·위험 도메인 안내 | 키/색인 누락 UI 테스트, 영화는 위험 판단 도메인 아님 | 실제 API 오류·성능·비밀 비노출 점검 |
| 15 | 선택 심화 기능 구현 | F2013~F2016 코드 및 로컬 검증 추가 | 실제 GMS 비교·품질 검증 대기 |
| 16 | 문서·코드·검증 결과 정리·제출 | README·요구사항·설계·자동검증 문서 구성 | 실제 증빙·셀프/상호 체크·최종 제출 미완료 |

다음 실행 순서: 키 설정 → 6번 실제 색인 → 7~12번 실제 질문 검증 →
13~14번 실제 UI·예외 검증 → 16번 증빙과 체크리스트 정리.
