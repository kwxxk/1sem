## 로그인과 데이터 유지
체험 시작은 임시 서버 계정입니다. 마이 페이지에서 체험 기록을 유지한 회원가입을 제공하고, 회원 계정으로 다시 로그인하면 기록이 유지됩니다. 비밀번호는 해시로 저장합니다. 글·좋아요·담은 책은 서버 DB에 저장하며 작성자 권한은 닉네임 문자열이 아닌 계정 ID로 검사합니다.

이전 버전에서 현재 브라우저·주소에 남아 있는 체험 글은 마이 페이지에서 수동으로 가져올 수 있습니다. 원본은 유지하고 현재 로그인 계정의 글로 복사합니다. 이전 브라우저 탭을 이미 닫았거나 다른 주소에서 저장했던 데이터는 이 페이지에서 자동으로 읽을 수 없습니다.

## 정보나루 실제 승인 상태
전달받은 정보나루 인증키는 `.env`에 설정했습니다. 실제 호출 결과는 `vitalizationErr`, 메시지는 ‘API 활성화 상태가아닙니다.’였습니다. 따라서 도서관이 없다고 표시하지 않고 승인 대기로 안내합니다. 승인 후 같은 조회를 다시 실행하면 됩니다. 인증키를 화면 코드나 보고서에 기재하지 않았습니다.

소장 도서관/대출 가능 여부는 승인 후 실제 자료로 추가 검증이 필요합니다. 정상 응답의 Y/N 처리와 지도 목록 구성은 테스트 응답으로 검증했습니다. 대출 상태는 제공기관 안내에 따라 전일 기준이며 즉시 반영되는 실시간 정보가 아닙니다.

## 이번 검증
- 서버 HTTP + SQLite + 독립된 쿠키 계정 검사 42항목 통과: 회원가입, 로그인, 잘못된 비밀번호, 세션, CSRF/다른 출처 차단, 글 공유, 작성자 권한, 수정·삭제, 좋아요, 정렬, 관심 도서 격리, 재로그인 후 기록 유지, 체험→회원 전환, 비공개 파일 차단.
- 화면 DOM + 실제 HTTP 서버 + DB 통합 검사 23항목 통과: 체험 후 작성, 내 글, 회원 전환, 서로 다른 계정 조회, 관리 버튼 권한, 좋아요, 예시 필터, 일반 도서 상세, 담기/취소, 승인 대기 안내, 수정·삭제·확인, 이전 글 가져오기, 로그아웃 및 팝업 배경 정리.
- 도서관 API 검사 7항목 통과: 정상 응답의 목록·대출 Y/N 처리, 전일 기준 표시, 키 없음 처리, 실제 승인 대기 응답 처리, 키 미노출.

총 72항목을 통과했습니다. 테스트 계정과 글은 격리한 임시 DB에만 만들었으며 실제 사용자 DB에 테스트 내용을 넣지 않았습니다. 도서 메타데이터 UI는 이전에 확인한 응답 및 명시적인 테스트 데이터를 사용했습니다.

실제 브라우저의 시각 렌더링, 외부 지도 표시, 터치 조작은 환경 연결 제한으로 검증하지 못했습니다. DOM/HTTP 기능 검증과 시각 사용성 검증은 구분해야 합니다.

## 실행
이전 서버를 종료하고 `run.bat`을 다시 실행한 다음 브라우저에서 Ctrl+F5로 새로고침하세요. 서버 코드가 변경되어 새로고침만으로는 새 기능이 반영되지 않습니다.

기본 주소는 현재 컴퓨터의 `127.0.0.1:8000`입니다. 같은 서버의 여러 브라우저/계정에서 공유를 지원하며 외부 네트워크에 공개하는 배포나 다른 PC의 접근 설정은 수행하지 않았습니다.
