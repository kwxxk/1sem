# 03-pjt — ThRead

도서 검색, 독서 쓰레드, 계정별 관심 도서를 제공하는 Python + Bootstrap 프로젝트입니다.

## 실행
1. Python 3.10 이상을 설치합니다. 추가 Python 패키지는 필요하지 않습니다.
2. 실행 중인 이전 서버를 종료하고 이 폴더의 `run.bat`을 실행합니다.
3. `http://127.0.0.1:8000/06-main.html`에 접속합니다. 필요하면 Ctrl+F5로 새로고침합니다.
4. 수동 실행은 `python server.py`, 포트 변경은 `python server.py --port 8001`입니다.

HTML 직접 열기나 VS Code Live Server만으로는 로그인·검색·게시글 기능을 사용할 수 없습니다. 서버는 기본적으로 현재 컴퓨터의 127.0.0.1에서만 실행됩니다. 인터넷 호스팅이나 다른 PC에 대한 접속 공개는 하지 않았습니다. 동일한 서버에 연결한 브라우저/계정들은 같은 글을 봅니다.

## 계정과 기록
- 로그인 창에서 회원가입을 선택하면 아이디/비밀번호로 계정을 만듭니다. 비밀번호는 8자 이상입니다.
- 체험 시작은 서버에서 임시 계정을 생성합니다. 체험 계정도 글쓰기·담기가 가능합니다.
- 체험 계정의 마이 페이지에서 기록을 유지하고 회원가입할 수 있습니다. 체험 계정에서 로그아웃하면 같은 계정으로 돌아갈 비밀번호가 없으므로 계속 사용할 기록은 회원 계정으로 전환하세요.
- 회원 계정은 로그아웃 후 다시 로그인해도 내 글과 관심 도서가 유지됩니다.
- 계정·세션·글·좋아요·관심 도서는 `data/thread.sqlite3`에 저장합니다. DB를 지우면 이 기록도 없어집니다.
- 이전 버전의 글이 같은 브라우저·주소의 sessionStorage에 남아 있으면 마이 페이지에서 가져오기 버튼으로 현재 계정에 복사할 수 있습니다. 원본 체험 데이터는 삭제하지 않습니다.

## 쓰레드
- 메인과 도서 상세에서 작성합니다. 비로그인 상태에서 작성하면 로그인 후 작성창으로 이어집니다.
- 글 제목을 누르면 전체 내용을 읽고 좋아요를 누를 수 있습니다.
- 본인이 쓴 글만 수정·삭제할 수 있습니다. 삭제 전 확인 단계가 있습니다. 권한은 화면과 서버 양쪽에서 확인합니다.
- 최신순/인기순을 선택합니다. 인기순은 실제 좋아요 수, 동률은 최신 글 기준입니다.
- 예시 글은 배지를 표시하며 예시 포함 체크를 해제하면 실제 글만 보입니다.
- 마이 페이지에서 내 글을 읽고 수정·삭제하거나 담은 책의 상세로 이동하고 담기를 취소합니다.

## 도서 검색과 상세
- 검색창은 빈 상태로 시작합니다. 검색 제출 전에는 도서 API를 호출하지 않습니다.
- 제목/저자/ISBN 검색, 12개씩 페이지 전환을 지원합니다. ISBN은 하이픈을 제거하고 정확히 일치하는 결과를 선택합니다.
- 검색 결과와 모든 베스트셀러는 공통 `07-book_detail.html` 화면을 사용합니다. ISBN 또는 제목을 URL로 전달합니다.
- 데이터가 없는 항목은 정보 없음, 표지가 없으면 대체 이미지를 표시합니다. 가격은 등록 당시 예정가격입니다.
- 과제의 베스트셀러 순위·AI 추천 표지는 예시 자료이며 API 순위나 실제 AI 추천 결과는 아닙니다.

## 도서관 정보나루
- 상세 화면에서 지역을 선택해 소장 도서관과 대출 상태를 조회합니다.
- `libSrchByBook`과 `bookExist`를 연결했습니다. 정보나루 키는 `.env`의 `DATA4LIBRARY_KEY`로 서버만 읽습니다.
- 현재 전달받은 키의 실제 응답은 `vitalizationErr`(API 비활성화)입니다. 승인 대기 안내가 표시되며 승인 후 다시 조회하면 됩니다.
- 대출 상태는 제공기관 안내에 따라 전일 기준으로 표시합니다. 즉시 반영되는 실시간 대출 상태가 아니므로 방문 전 해당 도서관에서 확인하세요.
- 인증 대기·키 미설정·결과 없음·연결 오류를 구분합니다. 도서관을 누르면 지도를 해당 위치로 바꿉니다.
- 공식 문서: https://data4library.kr/apiUtilization

## API 키와 저장소
- 국립중앙도서관 키: `.env`의 `NL_CERT_KEY`
- 정보나루 키: `.env`의 `DATA4LIBRARY_KEY`
- 환경변수가 있으면 `.env`보다 우선합니다. 새 환경에서는 `.env.example`을 참고하세요.
- `.env`와 `data/`는 Git 제외 및 HTTP 접근 차단 대상입니다. HTML/JS와 응답에는 인증키를 넣지 않습니다.
- 비밀번호는 솔트가 포함된 PBKDF2 해시로 저장하고 로그인은 서버 세션을 사용합니다.

## PDF 요구사항
