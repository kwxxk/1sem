## PDF와 다르게 적용한 점과 남은 범위
1. **F301 로그인 상태**: PDF 예시는 처음부터 로그아웃 메뉴가 있지만, 사용자 요청에 따라 처음에는 로그인으로 표시합니다. 체험 로그인 후 로그아웃 메뉴와 F308 확인창을 사용할 수 있습니다. 실제 서버 회원 인증이 아닌 닉네임 기반 UI 상태입니다.
2. **F305와 F310 동시 유지**: 기본 배열은 필수 Flexbox, 심화 배열은 CSS Grid입니다. 메인은 심화 배열이며 버튼으로 기본 요구사항 화면을 확인할 수 있습니다.
3. **F311 대여 가능 도서관**: 전달받은 ISBN 서지정보 API에는 도서관별 소장·대출 상태가 없습니다. 반포도서관 위치 지도 및 공식 자료 검색 링크를 제공하며 대출 가능이라고 단정하지 않습니다. 실제 대출 가능 목록을 자동으로 제공하려면 별도 소장/대출 API가 필요합니다.
4. **F311 배경 파일**: 제공 폴더에 명세의 상세 배경이 없어 기존 채식주의자 표지를 `assets/book_detail/book_cover.jpg`로 복사해 사용했습니다.
5. **쓰레드·담기 저장**: 예시 게시글6개에 현재 탭에서 작성한 글을 추가합니다. 쓰레드는 sessionStorage, 담기는 localStorage에 저장합니다. 다중 사용자 서버 게시판은 아닙니다.
6. **지도**: Google 지도 iframe이므로 외부 연결이 필요합니다. 실제 렌더링과 현장 대출 가능 여부는 검증하지 않았습니다.

## 추가 도서 API 구현
- 샘플과 같은 국립중앙도서관 ISBN 서지정보 endpoint를 사용합니다.
- 키는 `.env`에서 서버만 읽으며 `.env`는 Git 제외 및 HTTP 접근 차단합니다. 프런트엔드 및 API 응답에 키가 없는지 검사했습니다.
- 제목/저자/ISBN 검색, 결과12개씩 이전·다음, 상세 팝업, 빈 검색창을 제공합니다.
- ISBN은 하이픈을 제거하고 완전히 일치하는 결과만 선택합니다.
- 베스트셀러 클릭 시 해당 제목으로 API 검색하며 채식주의자는 상세 페이지로 이동합니다.
- 실제 ISBN 9788936433598 조회 결과에서 채식주의자 / 한강 / 창비를 확인했습니다. 가격은 API 등록 당시 예정가격으로 표시합니다.
- 표지·페이지 등 누락된 항목은 대체 이미지 또는 정보 없음으로 처리합니다. 기존 베스트셀러 순위와 AI 표지는 과제 예시 자료입니다.

## 직접 확인 순서
1. run.bat 실행 → 검색창이 비어 있고 API를 자동 호출하지 않는지 확인한 뒤 검색어를 입력.
2. 제목/저자/ISBN 선택 후 검색 → 상세 정보 → 검색 페이지 이동.
3. 로그인 → 닉네임 → 로그아웃에서 취소·확정 확인.
4. 메인 장르의 기본/심화 배열 버튼 비교.
5. 채식주의자 클릭 → 서지정보 → 담기 토글 → 도서관/쓰레드 탭.
6. 체험 로그인 상태에서 쓰레드 작성 → 새 글이 첫 페이지에 보이는지 확인.
7. 375px·575px·576px·1280px 화면에서 Navbar, 장르·카드 열 수, Hero 줄바꿈, 표지 크기, 겹침을 확인.
